# Chronicle and keyboard shortcuts

Chronicle is the in-app activity log. It records useful application events—such as scene publication, dice rolls, feature changes, and warnings—so the DM can understand what happened without opening browser developer tools.

## Use Chronicle

Open the system-tray control to expand Chronicle. The newest entry is also shown in its compact preview. Use the level filters to narrow the log and the feature search field to find events from a particular tool, such as `dice`, `scene`, or `fog`.

The clear action removes current log entries from the tray. Chronicle is an operational aid, not a permanent campaign journal; use Roll History for the dedicated recent-roll record. Debug-level entries are shown only in development/debug mode, keeping the normal table session focused on actionable information.

## Keyboard shortcuts

Keyboard shortcuts only run when focus is not in a text field and, when a dialog is open, only Escape is active. Press `?` to open the in-app shortcut glossary.

| Shortcut | Action |
| --- | --- |
| `Alt+L` | Toggle Live mode |
| `Alt+S` | Focus the status-message field |
| `Alt+H` | Toggle roll history |
| `Alt+I` | Toggle the initiative card |
| `Alt+→` / `Alt+←` | Next / previous turn during initiative |
| `Alt+D` | Focus dice notation |
| `Alt+G` | Toggle grid overlay |
| `Alt+F` | Toggle fullscreen |
| `Alt+K` | Toggle grid lock shortcut |
| `Alt+P` | Toggle focus-pointer mode (DM) |
| `Alt+E` | Open the effects palette (DM) |
| `Escape` | Close the active dialog or cancel an active drawing action |

On macOS, the glossary presents platform-appropriate modifier symbols. Shortcuts using plain letters are deliberately not registered, reducing accidental triggers while typing or operating the table.
