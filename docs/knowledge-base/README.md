# Imperomancer knowledge base

This is the source material for the public help centre. It describes the experience as a Dungeon Master (DM) and calls out what is visible on the table display where that differs.

## Before you begin

Open the DM control screen and connect the Player/table display with **Go Live**. Most features are prepared on the DM screen and then synchronized to the Player display. A feature that says *table-visible* is included in that synchronized view; a *private* item remains on the DM screen.

## A useful session order

1. Create or select a scene, upload its image or video, then publish it.
2. Configure the grid. Calibrate the table once if physical one-inch cells matter.
3. Turn on optional presentation tools—fog, whiteboard, effects, and focus pings—as the encounter needs them.
4. Start initiative and use public or private rolls as appropriate.

Prepared scenes keep their own map presentation settings, including grid, fog, and persistent effects. This makes it practical to move between locations without rebuilding an encounter from scratch.
