# Status messages

Status messages are short, high-visibility prompts that appear over the table display. Use them for narration beats, reminders, or an immediate call to action.

## Send a message

1. Open **Status**.
2. Enter the message you want players to see.
3. Send it.

The newest message replaces any existing one and restarts its display timer. Messages automatically dismiss after a few seconds, so they are best kept concise. Use **Clear** to hide a message immediately.

## Use named effects

The status tool can also issue predefined emphasis messages such as critical hit, critical fail, combat start, and victory. These are useful for a dramatic shared moment without needing to type a custom line.

Status is session-wide and independent of the selected scene. It does not become part of the map, whiteboard, or scene setup. A disconnected player display cannot receive a new message, so reconnect it before relying on a status prompt during play.
