# Whiteboard

The whiteboard is a full-stage shared canvas for quick sketches, plans, and rules explanations. When shown, it deliberately replaces the scene on both the DM stage and the Player/table display, giving people standing around a horizontal table an unobstructed surface from every edge.

## Draw on the table

1. Open **Whiteboard** and select **Show whiteboard**.
2. The DM stage and Player/table display change to a clean, full-size white canvas.
3. Choose a tool, color, and stroke size in the DM controls.
4. Draw directly on the full DM canvas. The same mark appears on the table display.

| Tool | Use |
| --- | --- |
| Pencil | Freehand notes, diagrams, and quick sketches. |
| Highlighter | A translucent freehand mark for emphasis without hiding other writing. |
| Line | A precise straight connection. |
| Arrow | A line with a clear direction marker; useful for movement and plans. |
| Rectangle / Ellipse | Quick zones, containers, and callouts. |
| Eraser | Paints white over a mark without clearing the whole board. |

The color picker accepts any color. The quick swatches provide ink, red, amber, yellow, green, and blue. Stroke size ranges from fine annotation to a broad table-visible marker.

On the DM display, a circular cursor preview follows the pointer and matches the selected stroke width. It adopts the drawing colour for Pencil, Line, Arrow, and shapes; Highlighter uses a translucent preview; Eraser uses a dashed neutral ring. This preview is private to the DM so it does not distract the table while you position a mark.

For Pencil, Highlighter, and Eraser, drag to record a freehand path. For Line, Arrow, Rectangle, and Ellipse, press at the starting point and release at the ending point.

## Clear and hide

**Undo last** removes only the latest mark. **Clear board** permanently removes all current strokes. **Hide whiteboard** returns both displays to the scene without erasing strokes, so you can temporarily remove annotations and show them again later.

## How it scales

Whiteboard coordinates are normalized to the full displayed canvas rather than stored as bitmap pixels. A drawing therefore scales cleanly between the DM preview and the player/table display, even when their resolutions differ. Whiteboard content is session-wide rather than part of a prepared scene; clear or hide it when transitioning to a new encounter if it is no longer relevant.
