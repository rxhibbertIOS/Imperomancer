# Scenes and the table view

Scenes are reusable encounter backdrops. Each scene can hold an image or video, its own view position, grid configuration, fog strokes, and persistent effect layers.

## Prepare a scene

1. Open **Scene** on the DM control screen.
2. Use the plus button to make another prepared scene, or select a scene tab to edit it.
3. Give it a short, recognizable name. Scene names identify the tab and the currently published scene.
4. Choose an image or video. Images and videos are accepted; images are limited to 25 MB and videos to 50 MB.
5. Review the preview, then choose **Update Prepared Scene**. Uploading alone does not replace the scene.

Use the minus button to remove a prepared scene. At least one scene is always retained.

## Frame the view

Use the plus/minus controls to zoom, drag directly on the map to pan, and use the reset control to return to the fitted view. The view is saved with the prepared scene. This is especially useful when one source image contains several encounter areas.

Video scenes play on the table display when published. They are presented as background media; prepare the desired framing before you publish.

## Publish safely

Choose **Cut** for an immediate change or **Fade** for a gentle transition, then select **Publish to Table**. A fade first takes the current Player composition to black, swaps the scene while it is concealed, then reveals the new scene with its grid, fog, and scene-specific effects already in place. The selected scene becomes the player-visible scene. The status line identifies what is currently on the table.

Edits to the scene already on the table are marked as a **Draft** until you publish again. This lets you alter a map, grid, fog, or effect privately before revealing the change. **Clear Scene** removes the current media from the selected prepared scene; it is useful when you want to keep a scene slot but start its visual setup again.

## What moves with a scene

Grid type, grid alignment, grid size, fog configuration, and persistent effect layers are scene-specific. Combat initiative, status messages, whiteboard strokes, and focus pings are session-level tools, so treat them separately when changing scenes.
