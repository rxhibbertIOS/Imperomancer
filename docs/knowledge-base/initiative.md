# Initiative

Initiative creates a shared turn order for the DM and table display. The DM controls the roster and turn progression; the player display receives the active combatant, upcoming turns, round number, and presentation options.

## Start combat

1. Open **Initiative** and add the combatants. The trailing empty row is intentional: it makes rapid roster entry easier.
2. Enter a name for every participant. Mark player characters and defeated combatants as needed.
3. Enter an initiative value, or enter a bonus and leave initiative empty to roll a d20 automatically.
4. Choose **Start initiative**.

Combatants are sorted from highest initiative to lowest. If the first combatant is marked defeated, the tracker advances to the next available participant. A blank row is ignored, so it is safe to leave the final entry empty.

## Run turns

Use next/previous turn controls or the keyboard shortcuts to move around the order. Advancing past the final participant increases the round; moving backward across the first participant reduces it, without going below round one. Defeated combatants are skipped after a brief visual pause, but remain in the roster for reference.

You can mark a combatant defeated at any time. Removing a combatant adjusts the current turn safely; ending initiative clears the active order from the table without deleting the draft roster.

## Edit an active order

Choose edit to alter names, bonuses, initiatives, player flags, or defeated state. Saving re-sorts the order and tries to preserve the currently active combatant. Cancelling abandons the editing copy and keeps the live order unchanged.

## Display options

The initiative display can be collapsed, or switched to a 360° presentation with edges around the table. In 360° mode all edges are enabled to support players seated on different sides. Edge controls decide which sides receive the initiative information in the standard presentation.
