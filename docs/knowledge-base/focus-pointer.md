# Focus pointer

The focus pointer drops pulsing rings on the table to direct attention without changing the map or its layers.

## Use it

1. Open **Pointer** and choose a preset or custom color.
2. Select **Enable pointer**.
3. Click a place on the DM map preview to drop a focus ring.
4. Disable pointer mode when you are finished, then resume normal panning and map interaction.

Each ping remembers the color selected when it was placed. Changing the picker later affects only new pings. Multiple pings can remain visible at once; use **Clear pings** to remove them all.

## Best uses

Use a ring to identify the active combatant’s position, point at a newly revealed door, or clarify a player question without drawing a lasting mark. Pings are synchronized to the player display and remain positioned in scene coordinates during view changes. They are session-level signals, not saved scene layers, so clear them between encounters when appropriate.
